# KMP、Border 理论与失配树：习题分析

对应讲解：[kmp-and-border-theory.md](kmp-and-border-theory.md)。本文覆盖原文全部练习；已在正文展开的具名例题也保留分析入口。建议先独立尝试，再按需阅读。默认不附完整代码。

全文与讲解统一采用 **1-index 字符下标、闭区间**。前缀函数记作 $p[i]$，表示 $S[1..i]$ 的最长真 Border 长度，对应讲解中的 $f[i]$；$p[0]=p[1]=0$。长度为 $0$ 的前缀是空串，状态 $0$ 与空前缀对应，不表示字符下标。

## 1. CF1721 E — Prefix Function Queries

[原题](https://codeforces.com/problemset/problem/1721/E)

固定长串 $S$，每次独立附上一个短串 $T$，输出新增位置的前缀函数。逐次从 $p[|S|]$ 开始普通失配回退，单次可能扫过长串的一整条 Border 链；不同查询之间无法共享这次回退的均摊。

解决方法是预处理 KMP 自动机。设当前拼接串为 $U[1..L]$。$go[j][c]$ 表示已经匹配前缀 $U[1..j]$，再读字符 $c$ 后的匹配长度。只要下一个模式字符 $U[j+1]$ 已知，就有

$$go[j][c]=\begin{cases}j+1,&U[j+1]=c,\\go[p[j]][c],&U[j+1]\ne c,\ j>0,\\0,&U[j+1]\ne c,\ j=0.\end{cases}$$

先为 $S$ 建好行 $0,\ldots,|S|-1$。对某次查询，当前总长度为 $L$，附上 $c$ 时，先用已有行计算

$$p[L+1]=go[p[L]][c],$$

再依据新出现的字符 $U[L+1]=c$ 构造第 $L$ 行。由于 $p[L]<L$，前一式不会读取尚未构造的新行。依次处理本次短串，新增的行和前缀函数只供本次查询使用；下一次仍从原来的 $S$ 开始，并覆盖临时后缀。

字符集大小为 $\sigma=26$，总时间 $O(\sigma(|S|+\sum|T|))$，空间 $O(\sigma(|S|+\max|T|))$。不能把每个查询看作承接上一个查询，也不能只预处理 $S$ 的终态回退行后永久不变：附串后，“完整匹配 $S$”的下一字符已经来自当前查询。

## 2. CF1163 D — Mysterious Code

[原题](https://codeforces.com/problemset/problem/1163/D)

将主串中的星号替换为字母，最大化模式 $A$ 的出现次数减去模式 $B$ 的出现次数。出现允许重叠，因此状态要保留两套“当前后缀匹配了多长前缀”，不能匹配成功后全部清零。

分别建立 KMP 自动机。对每个状态和字符预处理二元结果：下一状态，以及本步是否完成一次匹配。若临时匹配长度达到模式全长，就记录得分 $+1$（对 $B$ 则为 $-1$），随后回退到该模式最长真 Border，供下一字符延续重叠匹配。

令 $f_i(p,q)$ 为填完前 $i$ 位、两模式状态分别为 $p,q$ 时能获得的最大分差。初始 $f_0(0,0)=0$，其他为负无穷。下一步填第 $i+1$ 位：该位置固定时只枚举该字母，星号则枚举 26 个字母：

$$f_{i+1}(p',q')\gets\max\bigl(f_{i+1}(p',q'),f_i(p,q)+hit_A-hit_B\bigr).$$

两个历史若末尾状态相同，未来每步能新增的匹配次数就完全相同；以前已经得到的分差只需保留最大值。每个完整匹配又恰好在其结束位置计一次，所以转移既不漏重叠，也不重复计数。

设主串长 $n$、两模式长 $a,b$，自动机 $O(26(a+b))$，DP 时间 $O(26nab)$、滚动空间 $O(ab+26(a+b))$。最后取所有终态最大值，不要求匹配停在状态零。全串填法的最优值可能为负，不能把不可达状态初始化为零。

## 3. CF432 D — Prefixes and Suffixes

[原题](https://codeforces.com/problemset/problem/432/D)

输出所有同时为前缀与后缀的长度，以及该前缀在全串中出现次数，出现允许重叠。对每个长度 $L=1,\ldots,n$，将节点 $L$ 连向父亲 $p[L]$，得到失配树。

每个结束位置 $i$ 自身先给节点 $i$ 一次贡献。前缀长 $L$ 在这个位置结束，当且仅当 $L$ 是节点 $i$ 的祖先（允许取自身）。因此先令 $cnt[i]=1$，再按长度从大到小执行

$$cnt[p[i]]\mathrel{+}=cnt[i].$$

得到的 $cnt[L]$ 就是长度 $L$ 前缀的出现次数。然后沿 $n,p[n],p[p[n]],\ldots$ 收集所有非零长度，逆序输出。节点 $n$ 也要包含，它虽然不是真 Border，却满足题目“前缀且后缀”的要求。

例如 `aaaa` 的有效长度为 $1,2,3,4$，出现次数分别为 $4,3,2,1$。重复位置被分别计入，但同一结束位置对于某长度只有一个祖先关系，不会重复贡献。

时间、空间均为 $O(n)$。这里无须显式建失配树邻接表，因为父亲长度总更小，逆长度顺序天然是一次后序汇总。

## 4. ABC257 G — Prefix Concatenation

[原题](https://atcoder.jp/contests/abc257/tasks/abc257_g)

用 $S$ 的若干非空前缀拼成 $T$，最少用几段？KMP 扫描 $T$，求每个结束位置 $i$ 的最长匹配长度 $p_i$：即 $T[1..i]$ 的最长后缀，同时是 $S$ 的前缀。若完整匹配 $S$，应先把全长记录为本位置的 $p_i$，下一字符才从失配位置继续。

令 $f[i]$ 为拼出前 $i$ 个字符的最少段数，$f[0]=0$。普通转移需要枚举所有可作最后一段的 Border 长度。但有一个额外性质：

$$f[0]\le f[1]\le\cdots\le f[|T|],$$

其中不可达记为无穷。证明是把任意可行拼接从右边截短：删去完整末段，或把最后剩下的一段截成更短的 $S$ 前缀，段数不会增加。因此越短的目标前缀，最优段数越小或相等；若短前缀不可达，更长的也不可能可达。

所以所有合法末段中，最长的 $p_i$ 留下最短的前驱前缀 $i-p_i$，不会比其他选择差：

$$\boxed{f[i]=f[i-p_i]+1\quad(p_i>0),}$$

$p_i=0$ 则不可达。每个候选必须确实是匹配的前缀，不能误以为“所有小于 $p_i$ 的长度都是同一位置的合法末段”；最优性只需要最长那个确实合法，再用 $f$ 的单调性比较其他合法长度。

KMP 与递推总时间 $O(|S|+|T|)$、空间 $O(|S|+|T|)$。$f[|T|]$ 无穷则输出 $-1$。这题的贪心来自可截短性，不能推广成“任意词典分词都取最长后缀”。

## 5. NOI2014 动物园

[原题](https://www.luogu.com.cn/problem/P2375)

长 $i$ 前缀中，求满足 $2b\le i$ 的非空 Border 个数 $num[i]$，最终乘 $num[i]+1$。设 $h_i$ 为最长合格 Border，全部合格长度恰好是它的失配祖先链，所以

$$num[i]=dep[h_i],\qquad dep[v]=dep[p[v]]+1\ (v\ge1),\quad dep[0]=0.$$

容易证明的做法是从 $p[i]$ 沿倍增祖先找到第一个不超过 $\lfloor i/2\rfloor$ 的长度，总时间、空间 $O(n\log n)$。但每个 $i$ 都朴素扫一遍完整 Border 链会在 `aaaa...` 上退化。

线性做法从 $h_1=0$ 开始，对 $i=2,\ldots,n$ 维护另一个长度指针 $j=h_{i-1}$，比较当前字符 $S[i]$ 与 $S[j+1]$：失配则 $j\gets p[j]$，匹配则加一；之后当 $2j>i$ 时继续令 $j\gets p[j]$。最后得到的就是 $h_i$。这里的 $j$ 是已匹配长度；若写成你提供的模板中“下一比较位置”的变量，则应相应使用 $j-1$ 判断长度。

关键不是猜测这个指针足够，而是证明：任意当前合格 Border $b>0$，删掉末字符后，$b-1$ 必为上一个前缀的 Border，且 $2(b-1)\le i-1$。因此当前的全部候选只能由上一步已合格的链延伸而来，先前排除的过长候选不会突然变得需要考虑。普通 KMP 找最长可延伸者，再沿链筛长度门限，恰好得到最长合格者。

指针每轮至多增加一，所有回退都严格减小，总回退 $O(n)$；前缀函数与深度计算也线性，总时间、空间 $O(n)$。最后乘 $dep[h_i]+1$，加一表示空候选，而不是再给某个非空 Border 加权。例如 `aaaa` 在长度 4 时合格长度为 1、2，共两种，因子为 3。

## 6. ABC135 F — Strings of Eternity

[原题](https://atcoder.jp/contests/abc135/tasks/abc135_f)

在 $S$ 的无限重复串中，最多能连续匹配多少个 $T$？设 $n=|S|,m=|T|$。先对无限周期串的前 $n+m-1$ 个字符做 KMP，得到每个起点 $i\in[1,n]$ 是否能匹配一整份 $T$。后续起点按周期归一到位置 $1,\ldots,n$，因为原串周期为 $n$。

若位置 $i$ 匹配，则连有向边

$$i\to 1+((i+m-1)\bmod n).$$

走一条边就代表再接一份 $T$。每个点出度至多为 1：匹配失败便停止，匹配成功后的下一位置唯一。若图中有有向环，从环上开始可以无限接，输出 $-1$；否则求最长有向路径的边数。

可用三色 DFS：未访问、正在访问、已完成。遇到正在访问的后继说明有环；无环时 $dp[i]=1+dp[next(i)]$，无出边点为零。也可用入度拓扑排序，并对残留环判无穷，避免递归栈问题。

匹配文本不必真的无限展开，第 $j$ 个字符（$1\le j\le n+m-1$）读取 $S[1+((j-1)\bmod n)]$ 即可。总时间、空间 $O(n+m)$。特别地，$m$ 可以大于 $n$；若 $m\equiv0\pmod n$ 且某起点匹配，就会形成自环，应判无限而非只能匹配一次。
